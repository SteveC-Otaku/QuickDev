# 正式版本与构建产物

本地正式发布统一按版本存放，二进制不进入 Git：

| 版本 | 发布文件目录 | 保留内容 |
| --- | --- | --- |
| v0.2.0 | dist/v0.2.0/github/ | 官方 x64 安装包 |
| v1.0.0 | dist/v1.0.0/github/ | 官方 x64、ARM64 安装包与更新清单 |
| v1.0.1 | dist/v1.0.1/github/ | 官方 x64、ARM64 安装包、签名、更新清单和 SHA-256 |

各版本的 `oss/` 是完整官网部署目录，包含部署时需要的正式安装包副本。它们不是测试交付。文件完整性以 GitHub Release 的大小与 SHA-256 校验值为准。

2026-10-11 清理已移除 v1～v14 体验测试包、维护批次测试包、诊断程序、临时验证副本与原生打包目录中的重复安装包。历史构建记录保存在 `_tasks/2026-10-11-目录整理/build-records/`，逐文件迁移、删除清单为同目录的 `cleanup-completed.json`。

`npm run build:website` 优先使用本地正式发布目录中的安装包和 `.sig` 文件，可在清理原生安装包缓存后继续构建官网。`npm run release` 仍负责生成新的原生安装包。新的临时交付放到 `_tasks/YYYY-MM-DD-主题/`，正式版本放到 `release/dist/v<version>/`，避免再次堆积根目录 `dist/`。
