# Quick Dev 1.0.1 · 项目识别与网页入口修复

日期：2026-10-11。[GitHub Release v1.0.1](https://github.com/SteveC-Otaku/QuickDev/releases/tag/v1.0.1) 已发布 x64、ARM64 安装包、更新签名、latest.json 与 SHA256SUMS.txt，并设为最新版。官网 OSS 本次未部署。

## 用户可见变化

- 推荐方案按服务、启动顺序和打开目标去重；重扫保留手动命令、端口、地址和自定义方案，旧重复方案由用户选择移除
- 识别嵌套前后端与 workspace 服务目录，增加扫描边界和上限提示
- 读取 Vite 静态 host / port，支持运行时本地地址发现并核验监听进程归属；启动日志不再覆盖已保存的配置
- 主窗口与托盘共用打开逻辑，保留指定打开目标；缺地址和系统打开失败提供错误反馈
- 整理维护、回归和交付入口；各版本发布文件分开保存

## 升级与验证范围

新识别不再生成等价推荐方案。旧配置不会自动删除重复方案：编辑项目、重扫、选择移除重复方案，再保存。手工命令、端口、网页地址和自定义方案保留；必要时停止服务后修改配置。

Vite 地址识别只读取支持的静态字面量，不执行项目配置。动态函数、表达式及自定义 CLI 参数可能需要手填端口或地址。运行日志中的地址只属于当前启动代次，并验证监听进程归属。

未知端口仍使用 500ms 进程存活判断，不能证明 HTTP 服务已就绪。自动回归覆盖检测、方案合并、配置回读、运行时地址与托盘入口判定。前端检查、自动回归与 GitHub CI 通过；x64、ARM64 打包完成，两个安装包均通过内置公钥验证更新签名，GitHub 上六个发布文件的大小和 SHA-256 与本地一致。没有安装软件或进行真实桌面、托盘、系统浏览器及 ARM64 设备运行验收。未改动用户项目配置，未启动 IELTS。安装包未做 Windows 发布者代码签名。
